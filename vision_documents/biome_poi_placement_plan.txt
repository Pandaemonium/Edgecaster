Biome-Aware POI Placement Plan
===============================

This plan builds on the newly integrated 21-biome climate system to place POIs
based on environmental suitability. It follows the architecture from
site_generation_strategy.txt: meaning-first placement via suitability maps.

-------------------------------------------------------------------------------
CURRENT STATE
-------------------------------------------------------------------------------

What we have:
- 21-biome climate system in edgecaster/climate.py (Biome enum, classify_biome())
- ClimateConfig in game.py with 25+ tunable parameters
- Biome IDs stored on tiles via mapgen.py (tile.biome_id)
- POI system in content/pois.yaml with coord-based placement
- Spawning pipeline in systems/spawning.py + prototypes.py
- Site generation strategy doc outlining SiteSpec + suitability maps

What we need:
- Procedural POI placement based on biome suitability
- New faction/creature types for different biomes
- Integration with the existing POI/discovery system

-------------------------------------------------------------------------------
BIOME-TO-POI MAPPING (Examples from User)
-------------------------------------------------------------------------------

High-Level Biome Categories:
  WATER:      Ocean, Lake, River
  COLD:       Ice, Tundra, Taiga, Snow
  TEMPERATE:  Temperate Forest, Temperate Rainforest, Temperate Grassland, Shrubland
  HOT/DRY:    Scorched, Subtropical Desert, Temperate Desert, Savanna, Bare
  TROPICAL:   Tropical Forest, Tropical Rainforest
  CORRUPTED:  Corrupted Wasteland, Corrupted Forest, Corrupted Water

Proposed POI Types by Biome Affinity:

1. Bird People Settlements (Aeries)
   - Primary: Snow, Bare, Tundra (high elevation, cold, exposed)
   - Secondary: Temperate Grassland (open sightlines)
   - Suitability: E > 0.7, T < 0.4, moisture low-medium
   - Structures: cliff towers, nest platforms, open arenas
   - NPCs: bird_elder, bird_merchant, bird_scout
   - Enemies: territorial bird_warrior, trained hunting_hawk

2. Fishing Villages
   - Primary: Shore tiles adjacent to Ocean/Lake/River
   - Secondary: Temperate Rainforest coast (abundant seafood)
   - Suitability: within 2 tiles of water, E in [0.15, 0.35]
   - Structures: docks, fish_market, net_huts
   - NPCs: fishmonger, boat_captain, net_mender
   - Enemies (rare): sea creatures if corrupted water nearby

3. Spriggan Elder Trees (Groves)
   - Primary: Temperate Rainforest, Tropical Rainforest (high moisture forests)
   - Secondary: Temperate Forest, Taiga (any significant forest)
   - Suitability: M > 0.6, forest biome, low corruption
   - Structures: elder_tree (central), saplings, fungal_circles
   - NPCs: spriggan_elder (ancient tree spirit), moss_keeper
   - Enemies: thorn_guardians, bark_golems (if disturbed)

4. Desert Nomad Camps
   - Primary: Subtropical Desert, Temperate Desert, Scorched
   - Secondary: Savanna edges
   - Suitability: M < 0.25, T > 0.5
   - Structures: tent_cluster, oasis (if water nearby), trade_post
   - NPCs: nomad_chief, caravan_merchant, water_diviner
   - Enemies: sand_stalker, dust_wraith

5. Taiga Hunter Lodges
   - Primary: Taiga, Tundra edges
   - Secondary: Temperate Forest (cold regions)
   - Suitability: T in [0.2, 0.4], forest or shrubland
   - Structures: lodge, fur_rack, trap_workshop
   - NPCs: trapper, fur_trader, hunting_guide
   - Enemies: wolves, bears (beast faction)

6. Tropical Shaman Shrines
   - Primary: Tropical Forest, Tropical Rainforest
   - Secondary: Savanna (hot grasslands)
   - Suitability: T > 0.6, M > 0.4
   - Structures: shrine, ritual_circle, spirit_totem
   - NPCs: shaman, spirit_speaker, offering_keeper
   - Enemies: jungle_cat, venomous_snake

7. Corruption Cult Outposts
   - Primary: Corrupted Wasteland, Corrupted Forest
   - Secondary: High-corruption zones of any biome
   - Suitability: corruption > 0.15 (uses existing corruption field)
   - Structures: obelisk, ritual_pit, caged_subjects
   - NPCs: cult_leader, corrupted_merchant (sells cursed goods)
   - Enemies: cultists, summoned demons

(Dwarves removed - they will appear only underground)

PHASE 1: Data Structures & Suitability API

Step 1.1: Create SiteSpec dataclass
  File: edgecaster/state/sites.py (new)

  @dataclass
  class SiteSpec:
      id: str                    # Unique stable ID
      kind: str                  # "bird_aerie", "fishing_village", etc.
      coord: Tuple[int, int, int]  # (zx, zy, depth)
      seed: int                  # Derived from world seed + coord + kind
      biome: Biome               # Primary biome at this location
      tags: Dict[str, Any]       # Faction, size tier, etc.
      visibility: str = "hidden" # "hidden", "rumored", "discovered"
