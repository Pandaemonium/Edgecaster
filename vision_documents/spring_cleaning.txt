SLICE 2: Menu & UI System Rework [CLEANUP — ACTIVE]

Problem:

code and scene-specific hacks (especially for visuals and mouse hit-testing).

New foundation (now real):
✓ PanelScene: panel-local rendering + root widget tree + UI-first input routing
✓ GeneralMenuScene: selection model + confirm/cancel + scrolling
✓ Legacy wrappers: MenuScene and PopupMenuScene wrap GeneralMenuScene
✓ VisualProfile / VisualEffects apply consistently via visuals.py + visual_effects.py
✓ Mouse hit-testing works under rotation/scale via unproject_mouse(...)
✓ MenuFrameWidget provides a sane shared layout (banner/body/list/footer)
✓ Title hierarchy restored (big title header; normal body/options; tiny footer)
✓ UrgentMessage/Dialogue: wrapped body + wrapped choices (no ellipses)
✓ Popup underlay: “no burn-in” snapshot rebuilt from stack below popup
✓ Popup underlay: “no flicker” by suppressing renderer.present/_present during snapshot rebuild

Important gotchas learned (don’t regress):

Init ordering: GeneralMenuScene builds widgets during init and may call
get_ascii_art() early. Subclasses MUST set fields used by get_ascii_art()
BEFORE calling super().init().

MenuFrameWidget must clamp list/body widths to panel width to avoid clipped tails.

Popup underlay rebuild MUST suppress ALL presentation calls:
some scenes use renderer.present(), others call renderer._present() directly (DungeonScene).
If not suppressed, you will see “blink back to dungeon” when popups appear.

Import hygiene: avoid circular imports (events ↔ scenes ↔ renderer). Prefer:
from edgecaster.scenes.manager import SceneManager
and avoid importing SceneManager from edgecaster.scenes package root.

Temporary scaffolding (do not let this linger):

dungeon.py still contains an F8 debug overlay used to validate widget input
interception. Keep as fallback until widget-based HUD is stable across
Dungeon + Inventory + Popup flows, then remove.

Migration order (stay disciplined):
HUD → widget in its own file (overlay layer) [DONE]
Ability Bar → widgetized + preserve clickiness [DONE]
MenuScene/PopupMenuScene → wrappers over GeneralMenuScene [DONE]
InventoryScene/UrgentMessageScene/Dialogue → parity first; now wrapped text + snug popups are in place
Next: Two-pane inventory; keybinds/options as widget panels; reduce legacy UI paths.
